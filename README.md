# Baldr SKy DiveX Mod 使用指南

本项目是为《BALDR SKY DIVEX（日文原版）》制作的非官方 Mod 合集。通过替换或追加游戏的 `UpdateX.pac` 文件，可以加载新角色、强化原有技能，或体验自定义关卡。

目前所有 Mod 仅适用于**日文版游戏**。

 [日本語 READMEはこちら](https://github.com/Karaik/DX_MOD_PAC/blob/main/README_JA.md)

---

## 📦 使用方法

1. 将对应的 Mod 文件重命名为：

   ```
   UpdateX.pac
   ```

   其中 `X` 是当前 Update 文件中最大的编号 + 1（例如已有 `Update3.pac`，则改为 `Update4.pac`）。

2. 将文件放入游戏根目录。

3. 启动游戏，Mod 会自动生效。

### JINKI強化版.pac

- **作者**：[@柚木式子](https://space.bilibili.com/1420258295)
- **概要**：对部分武装进行了底伤强化，同时「ファントム」（空中三连）新增随时取消机制。
- **改修内容**：

  ```
  ファントムエッジ 20→60
  空中ファントム 30→75
  ハンマーブロウ 20→150
  幻刃閃 20→125
  ファントム的取消逻辑
  ```

- **作者**：[@；）](https://github.com/semicolonclosingbracket)
- **概要**：替换原游戏中的地狱模式 1～50 关为全新关卡。部分关卡拥有特殊机制或趣味设计。
- **难度范围**：难度从原版 60 到高于 94 都有，部分关卡更具挑战性。
