# BALDR SKY DiveX Mod 使用ガイド

本プロジェクトは『**BALDR SKY DiveX**』向けに制作された**非公式 Mod 集**です。  
`UpdateX.pac` ファイルを置き換えまたは追加することで、新しい機体の使用、の強化、カスタムステージの体験が可能になります。


[简体中文](https://github.com/Karaik/DX_MOD_PAC/blob/main/README.md)

---

## 📦 使用方法

1. 該当する Mod ファイルを以下のようにリネームしてください：

   ```
   UpdateX.pac
   ```

   ここでの `X` は、現在ゲームフォルダに存在する `Update` ファイルの最大番号 + 1（例：`Update3.pac` があれば → `Update4.pac` 、最大 7 まで追加可能）。

2. ファイルをゲームの**フォルダ直下**（`BaldrSky.exe`と同じ階層）に置きます。

3. ゲームを起動すれば、Mod が自動的に適用されます。
